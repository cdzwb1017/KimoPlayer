# KiomPlayer v1.4.2 更新日志

## 🏷️ 音频质量标签

### 新增功能
- **歌曲质量标签**：播放列表中的歌曲现在会显示音频质量标签（如 MP3、Hi-Res、SQ 等），方便快速识别音质。
- **可自定义显示**：可在设置中选择开启或关闭质量标签显示。

## 🛠️ 关于页面升级

### 框架技术展示
- **技术栈图标**：关于页面新增 Tauri、Rust、Vite、JS 框架小图标，直观展示技术栈。

### 历史更新记录
- **查看历史更新**：新增「查看历史更新」按钮，点击可弹出模态框查看历史版本更新内容。
- **持续更新**：后续新版本的更新记录将持续收录。

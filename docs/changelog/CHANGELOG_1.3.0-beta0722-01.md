# KiomPlayer v1.3.0-beta0722-01 更新日志

## 🎨 界面优化

### 歌词界面动画优化
- 优化歌词设置面板展开/收起动画，使用 `max-width` + `opacity` 平滑过渡
- 移除 `transform` 滑动动画，避免动画冲突导致的视觉异常
- 齿轮按钮固定在右上角，展开时控件向左平滑展开

### 歌词设置项调整
- 移除部分无用设置项目，简化设置界面
- 修复歌词页设置项目无法正常调整的问题

### 字体大小上限提升
- 歌词字体大小上限从 32px 提升至 **48px**
- 满足大屏设备或远距离观看需求

## 🐛 修复

- 修复歌词设置面板展开动画异常问题
- 修复设置项调整失效的问题
- 其他小问题修复

## 🏗️ 技术改进

- 优化 CSS 动画性能，使用 `max-width` 替代 `transform` 实现展开效果
- 简化歌词控制栏 DOM 结构

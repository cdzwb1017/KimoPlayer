# KiomPlayer v1.3.0-beta0721 更新日志

## 🆕 新功能

### 播放列表弹出面板
- 底部播放栏新增 **播放列表按钮**，点击可查看当前播放列表
- 显示歌曲封面、标题、歌手、时长
- 点击任意歌曲直接播放，当前播放歌曲高亮显示
- 支持从列表中移除歌曲，一键清空播放列表
- 播放切换时实时更新当前播放标记
- 毛玻璃风格，入场/退出动画

### 歌词行间距设置
- 系统设置新增 **歌词行间距** 滑块（0 ~ 2.0 倍字号）
- 可自由调整两句歌词之间的间距
- 拖拽即时预览，支持滚轮微调，持久化保存

## 🎨 界面优化

### 歌单详情页重构
- 完全重写歌单详情视图，使用 CSS 类替代内联样式
- **单击播放**替代双击播放
- hover 悬停效果（背景色变化 + 封面缩放）
- 入场动画（每行渐入 stagger）
- 删除按钮 hover 显示，红色悬停效果
- 返回按钮改用 SVG 箭头图标

### 动画体验升级
- 所有弹窗统一添加**退出动画**（淡出 + 缩放）
- 播放列表弹出面板、AI 校准弹窗、确认弹窗、命名弹窗
- 添加到歌单菜单增加入场/退出动画

### 封面显示修复
- 播放列表面板和歌单详情页封面改用 `<img>` 标签 + `object-fit: cover`
- 歌单列表卡片 2×2 拼图封面改用 `<img>` 标签
- 添加歌曲时自动异步补全封面（读取音频元数据）
- 渲染时无封面自动异步加载

## 🐛 修复

- 修复艺术家/专辑/歌单页面点击歌曲**不替换播放列表**的问题
- 翻译歌词间距改为紧贴主歌词
- 歌单列表歌曲支持右键菜单
- 修复歌单内歌曲的专辑封面无法正常显示
- 修复右下角歌词行间距过大的问题

## 🏗️ 技术改进

- 统一封面图片加载方式为 `<img>` + `object-fit: cover`
- 播放列表操作不再污染原有播放列表
- 简化歌单详情页 DOM 结构
